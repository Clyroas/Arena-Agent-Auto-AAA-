Help & privacy

If no answer appears

The panel will show a specific error instead of asking you to paste a reply.

  • No adapter: Connect now attaches the script automatically. If Chrome blocks it, check this extension’s Details → Site access for https://arena.ai and reconnect.
  • Control not found: check you are in Agent Mode. The page markup may need an adapter update.
  • Verification or rate limit: complete the check or follow the wait time in Arena. Nothing will be bypassed.
  • Timed out or ambiguous: inspect Arena before resending. The request may already have been accepted.

Recognized clarification cards can be answered here after explicit submission. You can stage images and supported files in this panel (paste, drop or attach) and they are placed into the Arena composer immediately before your one Send click. Security checks, execution approvals, tool controls and previews stay in Arena. Live text and tool labels are previews, not the completed answer.

Chat stays in memory · no API key · no credential access

Only appearance preferences and floating-window bounds are saved. Closing the side panel or window, or disconnecting, clears its chat. Switching tabs, minimizing or covering it does not. Arena may continue a request already sent. For a new conversation, use New Chat in Arena, then reconnect.

If you see Copy prompt or a reply-paste box, you have opened an older extension—not this automatic-only edition.

Arena terms ↗

Chat mode & model

Arena lists its models on Direct chat pages. Open a new Direct chat to pick one — it will appear here.

Picking a model opens a new Direct chat in your Arena tab using Arena’s own model link. Nothing is sent. This panel’s chat view is cleared; your Arena history is unchanged. The model of an existing chat is never changed.
